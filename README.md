# AURORA — Mission 01

> **Live Website:** https://aurora-launch-seq.lovable.app/

## Cinematic 3D Spacecraft Launch Experience

AURORA — Mission 01 is an immersive 3D spacecraft launch website built around a cinematic orbital mission experience.

The website presents the spacecraft and its launch sequence through a dark aerospace-inspired environment, combining 3D visuals, mission-control information, telemetry, and scroll-driven storytelling.

## Experience

The experience begins with a minimal dark interface and the message:

> GO BEYOND.

The user is introduced to:

**AURORA — MISSION 01**

with options to:

- Explore the Mission
- Learn More

The website uses scrolling as the primary way to begin and progress through the experience.

## Mission Control

A mission-status interface presents the state of the spacecraft systems:

- Structural — Ready
- Avionics — Nominal
- Propulsion — Armed
- Navigation — Locked
- Communication — S-Band OK
- Propellant — 100%

The system status concludes with:

> ALL SYSTEMS GO

## Ascent Telemetry

The website presents live-style spacecraft telemetry, including:

- Mission Time
- Altitude
- Velocity
- Downrange Distance
- Throttle
- Flight Stage

The flight sequence begins with:

**Stage 01 · BOOST**

This gives the experience the appearance of a real aerospace mission-control system rather than a conventional landing page.

## Visual Experience

AURORA uses a dark, cinematic visual language centered around the spacecraft and its mission.

The experience features:

- 3D spacecraft visuals
- Dark aerospace environments
- Mission-control styling
- Minimal typography
- Technical telemetry
- Cinematic presentation
- Immersive scrolling
- Orbital mission aesthetics

The overall design is intended to feel like an interactive spacecraft mission rather than a traditional website.

## Mission

**AURORA Mission 01**

**Mission Type:** Orbital

The experience focuses on the spacecraft's journey beyond Earth, combining 3D visuals, telemetry, and cinematic interaction to create an immersive launch experience.
